# Student Performance Analysis

This Python project generates random student data, calculates total marks, percentage, grades, and visualizes the results using matplotlib.

## Features
- Generates random student names and IDs
- Calculates total marks and percentages
- Assigns grades based on percentage
- Visualizes topper marks, average marks, and grade distribution

## Requirements
- Python 3.x
- numpy
- pandas
- matplotlib
- faker

## Usage
```bash
python student_performance.py
